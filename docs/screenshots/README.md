# HireFlow Screenshots & Assets

Place your 5 project screenshots in this folder with the following filenames:

1. `landing_hero.png` — Starry night landing page with the hero headline and buttons.
2. `auth_modal.png` — Get started / Welcome back modal with Google login & email/password.
3. `jobs_discovery.png` — Job search page with platform toggles (Greenhouse, Lever, etc.) and match percentages.
4. `auto_apply_modal.png` — AI Agent auto-apply modal (Browserbase / Stagehand).
5. `profile_skills.png` — Profile completeness gauge and interactive skill chips.

Once saved here, they will automatically render inside the root [README.md](../../README.md)!
